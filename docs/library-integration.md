# Integração com Biblioteca — descontinuada neste pacote

A aplicação Biblioteca e seu atalho foram retirados a pedido do projeto.
Não há um segundo serviço Flask nem um cliente Biblioteca gerado para novas
instalações. Um cliente antigo pode permanecer em um realm já existente, sem uso.
Não apagamos o banco existente para removê-lo. Veja [o fluxo atual](sso-flow.md).
